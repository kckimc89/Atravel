🌏 세계 여행대백과 · 41개국

나라를 선택해 여행을 시작하세요.

⏳ 기존 사진과 검색기억을 확인하고 있습니다. 자료를 삭제하거나 다시 선정하지 마세요.
⚙️ 관리 · 검색기억 · 백업

기존 명소대백과 원본은 변경하지 않습니다. 이 앱은 별도 저장공간을 사용하며 검색결과의 사진 주소·출처를 저장합니다.

기본사진은 이 기기의 저장소에 따로 보관합니다.
🖼️ 기본사진 선정 기준

① 명소를 한눈에 알아보는 전체 모습 ② 대표 건축물·중심 풍경 ③ 다른 각도 또는 계절·야경 ④ 명소만의 특징 ⑤ 내부·세부 모습. 같은 종류 사진만 5장 선정하지 않습니다. 사용자 지정사진은 자동으로 교체하지 않으며, 「사진 여행」에서 직접 교체한 뒤 정확 백업하세요.

💾 백업 · 복원

백업은 위의 「지정 기본사진 · 정확 백업」 한 번. 복원은 원본 전체 ZIP 파일 하나를 선택한 후 「전체 복원 시작」을 누릅니다. ZIP 전체를 메모리에 읽지 않고 지정사진을 한 장씩 검증해 저장합니다. V3.9.5 백업은 기존 사진과 달라도 백업의 지정사진을 복원합니다. 다만 iPadOS 파일 선택기에서 큰 파일 선택 자체가 중단될 수 있습니다.

📦 파일 앱에서 ZIP 묶음을 끌어 놓으세요

파일 앱에서 ZIP 묶음을 이곳으로 끌어 놓거나, 복사한 ZIP을 붙여넣어 보세요. 기기에 따라 파일 데이터 붙여넣기는 지원되지 않을 수 있습니다.

드래그가 안 되는 기기에서는 아래 파일 선택을 여러 번 이용할 수 있습니다. 선택한 파일은 누적되며 복원 실행은 한 번만 누릅니다.
선택된 ZIP 없음
복원은 모든 묶음이 등록된 뒤 한 번만 시작합니다. 파일 앱이 ZIP의 복사를 지원하지 않으면 파일 선택으로 누적 등록할 수 있습니다.
원본 전체 백업 ZIP 1개를 선택해 주세요. 사진 2,691장은 한 장씩 복원합니다. 먼저 파일 선택 성공 여부부터 확인하세요.

⚠️ 원본 606MB ZIP은 선택창을 여는 과정에서 iPadOS가 앱을 종료할 수 있습니다. 선택만 성공하면 ZIP 전체를 불러오지 않고 사진을 순차적으로 복원합니다. 기존 ZIP과 Safari 원본은 절대 삭제하지 마세요.

고급 도구 · 안전 이전용 백업 만들기 및 기존 복원 방법

🧰 대용량용 예비 백업 · 기존 분할 백업

위 「전체 백업」은 사진과 설정을 하나의 ZIP 파일로 만듭니다. 대용량 단일 ZIP이 기기 메모리 문제로 진행되지 않을 때 아래 예비 분할 백업을 이용하세요. 사진을 다시 검색하거나 내려받지 않습니다.

🧳 대용량 안전 이전 · 한 번에 복원

홈 화면 앱이 600MB ZIP을 선택할 때 멈추는 문제를 피하기 위한 새 경로입니다. Safari에서 「안전 이전용 백업 만들기」를 한 번 누르면 하나의 이전용 ZIP이 저장됩니다. 파일 앱에서 그 ZIP의 압축을 풀고, 홈 화면 앱에서는 안쪽의 작은 ZIP 묶음들을 모두 한 번에 선택한 후 「전체 복원 시작」을 한 번 누르세요.

✅ 기존 통합 백업에서 안전 이전본 만들기 (권장)

이미 파일 앱에 저장한 606MB 통합 백업 ZIP을 Safari에서 한 번 선택해 주세요. 앱의 사진 저장소를 다시 읽지 않고, 이 ZIP의 사진을 약 14MB씩 작은 ZIP에 나눈 뒤 다운로드 파일 1개로 묶습니다. 원본 ZIP은 변경하지 않습니다.

먼저 Safari에서 기존 전체 백업 ZIP을 선택하세요. 홈 화면 앱에서는 대형 ZIP을 선택하지 마세요.

새 이전용 ZIP은 파일 앱에서 한 번 압축을 풀어야 합니다. 안쪽의 작은 ZIP을 모두 한 번에 선택하세요. 이전 606MB 백업은 절대 삭제하지 마세요.

아직 이전용 묶음 파일을 선택하지 않았습니다.
기존 사진을 삭제하거나 덮어쓰지 않습니다. 이전용 묶음 전부가 확인되어야 복원을 시작할 수 있습니다.

📂 통합 ZIP 복원 · 2단계

① 아래 파일 선택을 직접 눌러 원본 ZIP을 선택하세요. ② 파일 이름이 표시되면 「복원 시작」을 누르세요. 선택만으로는 복원하지 않습니다.

아직 파일을 선택하지 않았습니다.

홈 화면 앱에서 iPadOS 파일 선택창 자체가 검게 멈추면 기기 파일 선택 기능의 문제일 수 있습니다. 앱을 삭제하거나 저장 데이터를 지우지 마세요.

먼저 「실제 사진 용량 확인」으로 저장 사진의 실제 크기를 확인하세요. 단일 ZIP은 Safari의 기기별 메모리 상황에 따라 실패할 수 있습니다.

🌏 나라별 사진 자동선정

나라를 선택하면 사진 자동선정을 시작할 수 있습니다.
